Edge Delta is an AI-powered observability platform that pairs enterprise-grade telemetry pipelines with agentic AI Teammates for SRE, security, and DevOps teams. Its intelligent pipelines control and route logs, metrics, traces, and events from any source to any destination with in-stream reduction, shaping, and enrichment, while AI Teammates continuously analyze streaming production data to automate root cause analysis and reduce alert fatigue. Edge Delta exposes a public REST API (X-ED-API-Token auth) for managing pipeline configurations, integrations, dashboards, lookup tables, and rehydrations, plus querying logs, metrics, and events — complemented by the edx CLI, an official MCP server, a Terraform provider, and published Agent Skills.

**Areas:** Company · Observability · Telemetry Pipelines · Logging · Metrics · Tracing · Monitoring · DevOps · SRE · Artificial Intelligence
